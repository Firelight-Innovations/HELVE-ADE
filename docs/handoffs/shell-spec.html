RESPONSIVE RULE

The inline menu block ends around 382px and the centred title starts around 525px at 1200px wide. Below roughly 1100px they collide — collapse the eight menu items into a single hamburger button that opens the same tree.

NOT DECIDED — DO NOT INVENT

How a tool mounts inside the tool window (iframe, separate OS window, or frontend module). Whether per-tool state gets a signal on the tab itself. What the engine status reports beyond the five stub strings above.

BUILD, DON'T DRAW

The worktree file list should come from an existing VS Code-style SCM component. Tool icons are placeholders — every tool shares one outline glyph until each earns its own. Names come from helve.toml; versions never reach the interface.

MOTION — REACT + FRAMER MOTION

Built in React with Framer Motion, targeting a modern desktop feel: smooth and responsive under load. Motion belongs to seven moments — switching tool tabs, collapsing and dragging the panel, the drag ghost and its drop targets, the boot spinner and progress, menus and the health popover opening, the search field expanding, and a detached window appearing. The four bars and their heights never animate; only what sits inside them moves. Terminal output and the worktree list must stay at native scroll speed — no animated list reordering.
